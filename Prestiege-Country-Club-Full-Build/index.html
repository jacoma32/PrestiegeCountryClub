GOLF IS A GAME OF FEEL.

Prestiege Country Club is a browser-based 3D golf project built for a school presentation. Features include three original course environments, nine playable holes, real-time ball flight, bunkers and water, scorecards, golfer selection, and animation support.

This is an independent school project. Not affiliated with PGA TOUR or 2K. Some gameplay and character systems are simplified relative to commercial golf simulators.
